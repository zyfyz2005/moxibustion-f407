## 四、分模块原理图详解

### 4.1 主控与时钟

- **位置**：原理图中央，U1，STM32F407ZGT6，LQFP144 封装。双列引脚布局：左列引脚（x≈196）网络名在 x≈177；右列引脚（x≈406）网络名在 x≈415。
- **HSE 8MHz**：PH0（OSC_IN）/PH1（OSC_OUT），配 C28 22pF、C29 22pF、R7 1M（并联反馈电阻）。
- **LSE 32.768kHz**：PC14（OSC32_IN）/PC15（OSC32_OUT）。
- **对项目的影响**：CubeMX 时钟树配 8MHz HSE 即可；LSE 供 RTC（本项目未用，但 IWDG 用的是 LSI，与 LSE 无关）。

### 4.2 调试串口（USART1 + CH340C）

- **位置**：左下 Sheet3，U4 CH340C，USB2 接口，标注 "USB USART"。
- **连接**（交叉）：
  - CH340C.TXD → PA10（USART1_RX）
  - CH340C.RXD ← PA9（USART1_TX）
- **外围**：C30 104（VCC 去耦）、R10 10K、R11 1M、R17 10K、C31 103 等。
- **对项目的影响**：调试日志走 USART1（PA9/PA10），与计划书一致，无需修改。

### 4.3 DHT11 / DS18B20 传感器接口（J6）

- **位置**：左上 Sheet1，标注 "DS18B20 & DHT11"，座子位号 J6。
- **J6 引脚定义**（放大复核，与计划书一致）：

  | 脚号 | 网络 | 说明 |
  |---|---|---|
  | 1 | VCC3.3 | 电源 |
  | 2 | DS18B20/DHT11（DQ） | 数据线，接 PG9 |
  | 3 | NC | 空脚 |
  | 4 | GND | 地 |

- **上拉**：R36 10K 将 DQ 上拉到 VCC3.3（板上已焊）。
- **对项目的影响**：
  - PG9 驱动单总线，DHT11 与 DS18B20 分时复用同一 DQ（计划书方案）。
  - ⚠ **接线提醒**：J6 是 4 针座，DHT11 是三针模块（VCC/DATA/GND），直接插会错位，必须杜邦线按 1↔VCC、2↔DATA、4↔GND 接。

### 4.4 按键（WK_UP / KEY0 / KEY1 / KEY2）

- **位置**：左下 Sheet3，KEY 区，4 个按键。
- **电路**：
  - **WK_UP 键**：一端接网络 WK_UP（PA0），另一端接 **VCC3.3**（标注 KEY_UP）。按下为高 → PA0 平时需下拉（上电默认低）。
  - **KEY0 / KEY1 / KEY2 键**：一端接网络（KEY0/KEY1/KEY2 → MCU），另一端**共同接 GND**。按下为低 → 引脚平时需上拉。
  - **⚠ KEY 区没有外部上拉/下拉电阻**：三个按键的"平时电平"完全靠 **MCU 内部上/下拉**（在 CubeMX 里选 Pull-up / Pull-down）。
    若误配成 `No pull`，引脚浮空，读数会随机跳、还会出现幽灵按键——这是按键调试里最常见的一个坑。
- **引脚映射**（从 MCU 封装区网络名逐脚核对）：

  | 按键 | F407 引脚 | 计划书用途 | 核对结果 |
  |---|---|---|---|
  | KEY0 | PE4 | 复位键（计划书误写 KEY2） | ⚠ 丝印应为 **KEY0** |
  | KEY1 | PE3 | 静音键 | ✓ |
  | KEY2 | PE2 | 未使用 | 补充：KEY2 在 PE2，本方案不用 |
  | WK_UP | PA0 | 开关机键 | ✓ |

- **对项目的影响**：按键扫描代码按 PE4（复位，丝印 KEY0）、PE3（静音，丝印 KEY1）、PA0（开关机）配置；**注释/文档中的 "KEY2" 应改为 "KEY0"**，避免对板子丝印找不到键。

### 4.5 蜂鸣器（BEEP）

- **位置**：左上 Sheet1，BEEP 区。
- **电路拓扑**（矢量线重建确认）：

  ```
  VCC3.3 ──► 蜂鸣器(P) ──蜂鸣器(G)──► Q2 集电极
                                        │ Q2 = S8050（NPN）
  BEEP 网络(PF8) ── R37 1K ──► Q2 基极
                                        │
                                R38 10K（基极下拉）
                                        ▼
                                      GND（Q2 发射极）
  ```

- **关键参数**：
  - 蜂鸣器：**无源**（M0 已确认），P 接 VCC3.3、G 接 Q2 集电极。
  - Q2：S8050 NPN 三极管，低端驱动。
  - R37：1K，基极限流电阻。
  - R38：10K，基极-发射极下拉（防误触发）。
  - **高电平导通**：PF8 输出高 → Q2 导通 → 蜂鸣器响。
- **⚠ 重要勘误（TIM 复用）**：计划书写 "PF8（TIM11_CH1）"。原理图 MCU 封装区注释明确：

  | 引脚 | 原理图注释的 TIM 复用 |
  |---|---|
  | PF6 | TIM10_CH1 |
  | PF7 | **TIM11_CH1** |
  | PF8 | **TIM13_CH1**（AF9） |
  | PF9 | TIM14_CH1 |

  因此蜂鸣器 PWM 应配置 **TIM13_CH1**（PF8，AF9）。若坚持用 TIM11_CH1，则引脚要换到 PF7（但 PF7 在板上接 LIGHT 光敏网络，不建议）。
- **报警频率**（沿用计划书）：温度报警 2 kHz、倒计时报警 3 kHz，节奏均为响 200ms / 停 150ms；静音时停 PWM。

### 4.6 状态灯（DS0 / DS1）

- **位置**：左下 Sheet3，LED 区。
- **电路**（共阳）：

  ```
  VCC3.3 ── R12 1K ── DS0 ── LED0 网络（PF9）
  VCC3.3 ── R14 1K ── DS1 ── LED1 网络（PF10）
  ```

- **关键参数**：DS0/DS1 发光二极管，限流电阻 1K（R12/R14），**共阳极接 VCC3.3**，**低电平点亮**。
- **对项目的影响**：LED 状态编码逻辑按"引脚输出低=点亮"实现（计划书已如此约定，与原理图一致）。

### 4.7 WiFi 模组（ESP8266）与 P10 跳帽

- **位置**：左上 Sheet1，"WIFI/Bluetooth/GPS" 区，P3 为 ESP8266 模组座。
- **P3 模组座引脚**（自上而下）：VCC、URXD、GPIO16、GPIO0、CH_PD、GPIO2、UTXD、GND。
- **板载引出网络**（P3 下方排针，按位置对齐确认）：

  | 板载网络 | 模组引脚 | 接 F407 | 功能 |
  |---|---|---|---|
  | VCC3.3 | VCC | — | 供电（C23 104 滤波） |
  | W_TX | **URXD**（模组 RX 输入） | PB10（USART3_TX） | MCU 发送 → 模组 |
  | W_LED | **GPIO16** | PC0 | 模组状态灯（读） |
  | W_KEY | **CH_PD** | PF6 | 模组使能（高有效） |
  | W_RX | **UTXD**（模组 TX 输出） | PB11（USART3_RX） | 模组发送 → MCU |
  | GND | GND | — | 地 |

- **P10 跳帽**（USART3 选择，位于 RS232/DB9 区旁）：
  - **P10 是 2×3 排针**（不是 1×6 单列）。按标准编号（1-2 一排、3-4 一排、5-6 一排）：
    左列自上而下 **6 / 4 / 2 = U3_TX / USART3_TX / W_TX**，右列自上而下 **5 / 3 / 1 = U3_RX / USART3_RX / W_RX**。
  - **出厂默认 WiFi**：跳帽短接 **(4,2)** 与 **(3,1)**，即 USART3_TX↔W_TX、USART3_RX↔W_RX。
  - 切 RS232：改短接 **(6,4)** 与 **(5,3)**（接 SP3232，DB9 母头）。
  - **以实物丝印为准**：上面的列序是按 2×3 排针的标准编号推的，上板前对着丝印确认一次。
  - **更正说明（v1.1）**：v1.0 写的"短接 1-3、2-4"是按 1×6 单列排针推的，依据不足。
    两种写法描述的**电气连接相同**（都是 USART3 接 WiFi），差别只在"排针形态 + 跳帽插哪两个孔"的表述上。
    接口是 2×3 而不是单列，所以按"1-3、2-4"去找孔会找不到——这才是必须改的实际原因。
- **⚠ 网络名勘误说明**：计划书 "PB10=TX→W_RX、PB11=RX←W_TX" 中，**网络名对应写反**。原理图上：
  - PB10(USART3_TX) 发往 **W_TX**（模组 URXD）
  - PB11(USART3_RX) 接收 **W_RX**（模组 UTXD）
  - 命名视角："W_TX/W_RX" 指"发往 WiFi / 从 WiFi 收"的线，不是模组的 TX/RX 脚。电气结果一致（MCU 发的数据最终进模组 RX），但代码注释与接线描述请按原理图网络名写。
- **对项目的影响**：CubeMX 配 USART3（PB10/PB11）；PF6 输出高使能模组；PC0 读模组 GPIO16 状态。P10 保持出厂默认 WiFi，勿动。

### 4.8 24C02 配置存储

- **位置**：右上 Sheet2，EEPROM 区，器件 U3（24C02）。
- **引脚连接**（放大复核）：

  | 引脚 | 网络/连接 | 说明 |
  |---|---|---|
  | 1 (A0) | GND | 地址位 0 |
  | 2 (A1) | GND | 地址位 0 |
  | 3 (A2) | GND | 地址位 0 |
  | 4 (GND) | GND | 地 |
  | 5 (SDA) | IIC_SDA（PB9） | 数据，R9 4.7K 上拉 VCC3.3 |
  | 6 (SCL) | IIC_SCL（PB8） | 时钟，R8 4.7K 上拉 VCC3.3 |
  | 7 (WP) | **悬空** | 写保护关闭（可写） |
  | 8 (VCC1) | VCC3.3 | 电源，C10 104 去耦 |

- **I2C 地址**：A0=A1=A2=0 → 7 位从机地址 **0x50**（8 位写地址 0xA0、读地址 0xA1）。
- **⚠ 重要勘误**：计划书写 "24C02 | PB6 / PB7 | I2C1"。原理图实际为 **PB8（IIC_SCL）/ PB9（IIC_SDA）**。PB6/PB7 在原理图上接的是 **DCMI_D5 / DCMI_VSYNC**（摄像头接口），不是 I2C。
  - PB8/PB9 同样复用 **I2C1（AF4）**，因此外设还是 I2C1，只需在 CubeMX 里把引脚选到 PB8/PB9。
- **对项目的影响**：
  - CubeMX：I2C1 引脚 = PB8（SCL）/ PB9（SDA），AF4。
  - 代码：config 读写地址 0x50；页大小 8 字节（跨页写回卷覆盖），约 20 字节配置需拆 ≥3 次页写（计划书已注意）。
  - 上电 `config_load()` 用 I2C 轮询；运行期 ConfigTask 独占 I2C1（`config_mutex`）。

### 4.9 电源

- **位置**：左下 Sheet3，POWER 区。
- **拓扑**：J3（POWER / DC_IN）→ V1（1117-3.3 LDO，IN=5V、OUT=3.3V）→ **VCC3.3**；C7 10uF、C8/C9 104 滤波；板上另有 VCC5。
- **对项目的影响**：DHT11（VCC3.3）、24C02（VCC3.3）、蜂鸣器（VCC3.3）、ESP8266（VCC3.3）全部由板载 3.3V 供电。ESP8266 发射瞬态电流较大，若出现 WiFi 掉线/复位，优先检查 3.3V 供电余量（可外接 5V 供电或独立电源给模组）。

### 4.10 复位电路

- **位置**：左下 Sheet3，RESET 区。
- **电路**：RESET 按键 → NRST；R22 10K 上拉 VCC3.3、C32 104 去耦；另有 BOOT0（R20 10K）、BOOT1（R21 2K）配置。
- **重要区分**：板上 RESET 键是**硬件复位**（NRST）；计划书的"复位键 PE4"是**软件复位**（状态机回 WAITING），二者不是一回事，代码里别把按键事件挂到 NRST。

## 七、接线与调试提醒

1. **J6 接线错位**：J6 是 4 针座（VCC/DQ/NC/GND），DHT11 是三针模块。杜邦线按 1↔VCC、2↔DATA、4↔GND 接，直接插会错位。
2. **CubeMX 必改项**：
   - I2C1 引脚 → PB8（SCL）/ PB9（SDA），AF4。
   - 蜂鸣器 PWM → TIM13_CH1（PF8），AF9；或改引脚到 PF7 用 TIM11_CH1。
   - HAL 时基从 SysTick 改到 TIM6（计划书要求，与原理图无关但必做）。
3. **P10 跳帽**：2×3 排针，出厂默认 WiFi = 短接 **(4,2)** 与 **(3,1)**；切 RS232 = **(6,4)** 与 **(5,3)**。
   调试 WiFi 前先确认 P10 没被拨到 RS232 一侧，并对着丝印核对一次列序。
4. **按键上下拉靠内部电阻**：KEY 区没有外部上/下拉，CubeMX 里 PA0 必须配 Pull-down、PE3/PE4 必须配 Pull-up；
   配成 `No pull` 会浮空误触发。
5. **两个复位**：RESET 键（NRST 硬件复位）与 PE4/KEY0（软件复位）区分清楚。
6. **WP 悬空**：24C02 可写；若以后程序写配置失败，检查 WP 是否被误接高电平。
7. **ESP8266 供电**：板载 3.3V 由 1117-3.3 提供，WiFi 发射电流大，掉线/复位优先查供电。
8. **IWDG 调试**：DEBUG 期必须冻结 IWDG（DBG_IWDG_STOP）或 Debug 构建不启动（计划书已有）。
